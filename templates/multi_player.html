Multi-Player Mode

Several firms, one market — compete head-to-head for the best deals and returns.

  1. One player creates the game (needs an access code) and gets a shareable join code.
  2. Everyone else joins with that join code — shown on every player's dashboard until the first Deal Process runs, so invite people early.
  3. Compete for the same companies — rival term sheets, co-invest offers, and syndicates. Each round advances once every team marks the phase complete.
  4. Settle it on the leaderboard after all 7 fund years.
